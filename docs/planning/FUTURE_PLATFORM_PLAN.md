## 1. 專案目標
建立面向同業的 B2B 線上自動化報價與接單平台。

- 24 小時自動接單。
- 提供初步自動報價。
- 減少深夜／凌晨人工溝通負擔。
- 依既有店鋪報價規則建立系統化計價流程。
- 初期以「簡潔利落」與核心功能落地為優先。
- 初期暫不提供 C 端直客下單。

## 2. 核心 B2B 報價與接單流程

### 2.1 快速估價

1. 客戶選擇衣物款式。
2. 客戶選擇印刷位置／尺寸。
3. 客戶選擇印刷設定。
4. 客戶輸入訂購數量。
5. 系統依現行報價規則即時計算。
6. 顯示預估單價與預估總價。
7. 客戶可修改條件並重新計價。

> 快速估價階段不要求客戶上傳原稿或示意圖。

### 2.2 報價確認

1. 客戶確認估價條件。
2. 建立報價資料。
3. 取得報價編號。
4. 客戶確認是否進入接單流程。

### 2.3 正式接單

1. 客戶上傳原稿。
2. 客戶上傳示意圖。
3. 系統保存稿件。
4. 客戶確認訂單資料。
5. 建立正式訂單。
6. 後續付款／人工確認流程 `[TBD]`
